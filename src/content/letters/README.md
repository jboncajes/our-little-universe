# Your letters

Put each monthly letter here as a plain text file, named by its month:

    month-01.txt
    month-02.txt
    …
    month-11.txt

The site uses the file as that month's full letter (when she opens the envelope).
A month without a file keeps showing the lines from `src/content/content.ts`.

- Leave a blank line between paragraphs; single line breaks are kept.
- Save as UTF-8 (Notepad's default) so emoji and accents show correctly.
- The title and the line on the month's page still come from `content.ts`.
